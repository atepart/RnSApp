#### Математическая оценка предложенных весов

- Основной тезис изображения корректен: для критерия
  `Σ Wᵢ(yᵢ - ŷᵢ)²` статистический вес должен быть `Wᵢ = 1/σᵧᵢ²`, если ошибки
  независимы, имеют нулевое среднее и известную неодинаковую дисперсию.
- Переход к `Wᵢ = 1/yᵢ²` корректен только при обоснованной модели постоянной
  относительной ошибки зависимой переменной: `σᵧᵢ = k·|yᵢ|`. Использование
  наблюдаемого `yᵢ` в весах может само вносить bias; предпочтительнее известная
  погрешность прибора, повторные измерения или итеративный вес по `ŷᵢ`.
- Замена `y` на `D` не следует просто из положительности или приблизительной
  пропорциональности. `Wᵢ = 1/Dᵢ²` соответствует отдельному предположению
  `σᵧᵢ ∝ Dᵢ`. Из-за ненулевого intercept физическая модель имеет вид
  `y = a(D - drift)`, поэтому `D` и `y` не строго пропорциональны.
- Предложенный столбец `1/D` имеет две разные возможные трактовки. Если это
  коэффициент `Wᵢ` непосредственно в `ΣWᵢrᵢ²`, он соответствует
  `σᵧᵢ ∝ √Dᵢ`, а не `σᵧᵢ ∝ Dᵢ`. Если это аргумент `w` для NumPy
  `polyfit`, который умножает ещё не возведённый в квадрат остаток, то
  `wᵢ = 1/Dᵢ` даёт итоговый критерий `Σ(1/Dᵢ²)rᵢ²` и соответствует
  `σᵧᵢ ∝ Dᵢ`. Эту семантику нельзя смешивать.
- Для используемого преобразования `y=(Rn+Rпосл)^(-1/2)` распространение
  погрешности даёт `σᵧ ≈ σRn / (2(Rn+Rпосл)^(3/2))`. При постоянной абсолютной
  погрешности R оптимальные веса пропорциональны `(Rn+Rпосл)^3`; при постоянной
  относительной погрешности R — `(Rn+Rпосл)=1/y²`. Ни один вариант в общем
  случае не равен `1/D`.
- Если существенная погрешность относится к диаметру D, обычный WLS по y её не
  учитывает. Тогда нужно отдельно рассматривать errors-in-variables/ODR с
  погрешностями по обеим осям, а не назначать эвристический вес `1/D`.
