# Changelog

## 2026-07-22

### Изменено

- `WORK-20260722-1` — XLSX визуально разделяет исходные данные, вычисляемые
  значения, веса и итоговые параметры цветными заголовками и спокойными фонами;
  строка заголовков закреплена, а для таблицы данных включён автофильтр.
- `WORK-20260720-5` — XLSX рассчитывает weighted linear fit собственной
  аналитической формулой через пять скрытых сумм `Σw`, `ΣwD`, `ΣwY`, `ΣwD²` и
  `ΣwDY`; критерий остался согласован с приложением:
  `Σ(1/D²)·(Y-slope·D-intercept)²`.

### Исправлено

- `WORK-20260722-1`, `BUG-20260722-1` — weighted fit-серия получает две
  кэшированные X/Y-точки и тип `lineMarker`, поэтому корректная красная линия
  видна при первом открытии файла, а после изменения данных продолжает
  обновляться по формулам листа.
- `WORK-20260720-5`, `BUG-20260720-2` — выбранные строки без числового
  `1/√Rₙ` больше не получают вес `1/D` и не попадают в Excel fit как ложные
  точки с `Y=0`. Контрольный файл после пересчёта дал ожидаемые
  slope/intercept `0,0500000392 / 0,1000007326` без ошибок формул.

### Документация

- `WORK-20260722-1` — README объясняет преобразование `Y`, множитель остатка
  `q=1/D`, фактический вес `w=1/D²`, критерий WLS, отбор строк и реализацию
  weighted fit в Excel без стандартной невзвешенной trendline.

## 2026-07-20

### Добавлено

- `WORK-20260720-2` ([GitHub issue #15](https://github.com/atepart/RnSApp/issues/15)) —
  XLSX каждого измерения теперь содержит последний столбец данных `Вес (1/D)`,
  взвешенные формулы slope/intercept и отдельную согласованную fit-серию вместо
  невзвешенной trendline Excel.
- `WORK-20260720-2` — создан набор из 13 автоматических тестов для WLS,
  XLSX round-trip, профилей графика, dock layout, миграции QSettings и полного
  нативного UI-сценария.

### Изменено

- `WORK-20260720-4` — сохранённый пользователем dock layout теперь всегда
  восстанавливается из `QSettings` независимо от старой метки версии; layout по
  умолчанию используется только при отсутствии сохранённого `state`. Запись
  `layout_version` больше не создаётся и удаляется при следующем сохранении.
  Проверки: 13 автоматических тестов и 3 нативных macOS Cocoa-теста layout
  пройдены.
- `WORK-20260720-3` — текст легенды увеличен с `12pt` до `16pt` во встроенном
  графике и с `20pt` до `26pt` в PNG/SVG/Copy. Проверки: 13 автоматических
  тестов и нативный macOS Cocoa-сценарий пройдены; длинная легенда визуально
  проверена на экране и в экспорте. Артефакты:
  `/tmp/rns-legend-16-26/02-recorded-cell-and-legend.png` и
  `/tmp/rns-legend-16-26/03-large-font-plot-export.png`.
- `WORK-20260720-2` ([GitHub issue #15](https://github.com/atepart/RnSApp/issues/15)) —
  линейная аппроксимация приложения и загрузчика XLSX использует множитель
  остатка `w=1/D`, то есть критерий `Σ(1/D²)·r²`; неположительные диаметры
  исключаются из fit.
- `WORK-20260720-2` — увеличены экранные подписи осей, tick labels и легенда;
  PNG, SVG и Copy используют отдельный более крупный профиль с защитой от
  обрезания и восстановлением экранного оформления после экспорта.
- `WORK-20260720-2` — стартовый dock layout версии 3 соответствует структуре
  issue: «Данные»/«Запись» слева, большой график справа, «Расчет»/«Действия» под
  ним и «Расчёт площади» отдельной нижней полосой.

### Исправлено
