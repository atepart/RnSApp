### BUG-20260720-2 — Пустой Rn искажает weighted fit в XLSX

- Дата: 2026-07-20
- Дата исправления: 2026-07-22
- Статус: Исправлен
- Серьёзность: Высокая
- Компонент: infrastructure
- Связанная работа: WORK-20260720-5
- Окружение: macOS, Python 3.11, openpyxl, LibreOffice 26.8; экспортированный
  формат XLSX предназначен для Microsoft Excel 16.93
- Предусловия: выбранная строка содержит положительный диаметр, но пустой или
  некорректный `Rn`; остальные строки достаточны для линейного fit.
- Шаги воспроизведения:
  1. Экспортировать ячейку с такой строкой в XLSX.
  2. Пересчитать формулы книги.
- Фактический результат: в `J` получается пустое значение, но в `K` остаётся
  вес `1/D`; `SUMPRODUCT` учитывает строку как точку с `Y=0`. На контрольных
  данных наклон/пересечение меняются с ожидаемых `0,05 / 0,10` на
  `0,0282608 / 0,0930442`.
- Ожидаемый результат: строка без числового `1/√Rₙ` полностью исключается из
  fit, как это происходит в приложении.
- Доказательства: исправленный файл
  `/tmp/rns-weighted-repo-final/rns-weighted-excel-missing-rn-diagnostic.xlsx`
  после пересчёта возвращает наклон/пересечение
  `0,0500000392 / 0,1000007326` и не содержит ошибок формул.
- Регрессионный тест: `tests/test_xlsx_weighted_fit.py`
- Проверки исправления: 7 релевантных тестов, полный unittest-набор и нативный
  Cocoa UI-сценарий пройдены; XLSX пересчитан LibreOffice 26.8 без ремонта.

### BUG-20260720-1 — Небезопасное закрытие всех top-level окон

- Дата: 2026-07-20
- Статус: Исправлен
- Серьёзность: Низкая
- Компонент: ui
- Связанная работа: WORK-20260720-2
- Окружение: macOS, Python 3.11, PySide6 6.8.2.1, Qt integration-тест
- Предусловия: вместе с главным окном существует другое top-level Qt-окно
- Шаги воспроизведения:
  1. Открыть RnSApp и дополнительное top-level окно графика.
  2. Закрыть главное окно RnSApp.
- Фактический результат: `closeEvent` повторно вызывал `close()` для самого
  главного окна и без защиты закрывал остальные окна; повреждённое окно графика
  могло вызвать `AttributeError` при закрытии.
- Ожидаемый результат: главное окно не закрывает себя рекурсивно, а ошибки при
  закрытии вспомогательных окон не прерывают завершение приложения.
- Доказательства: воспроизведено полным Qt test suite до исправления.
- Регрессионный тест: `tests/test_ui_integration.py`
- Проверки исправления: 13 тестов и реальный macOS Cocoa-сценарий пройдены.
