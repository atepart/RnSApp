## Исправленные дефекты

### BUG-20260720-1 — Небезопасное закрытие всех top-level окон

- Дата: 2026-07-20
- Статус: Исправлен
- Серьёзность: Низкая
- Компонент: ui
- Связанная работа: WORK-20260720-2
- Окружение: macOS, Python 3.11, PySide6 6.8.2.1, Qt integration-тест
- Предусловия: вместе с главным окном существует другое top-level Qt-окно
- Шаги воспроизведения:
  1. Открыть RnSApp и дополнительное top-level окно графика.
  2. Закрыть главное окно RnSApp.
- Фактический результат: `closeEvent` повторно вызывал `close()` для самого
  главного окна и без защиты закрывал остальные окна; повреждённое окно графика
  могло вызвать `AttributeError` при закрытии.
- Ожидаемый результат: главное окно не закрывает себя рекурсивно, а ошибки при
  закрытии вспомогательных окон не прерывают завершение приложения.
- Доказательства: воспроизведено полным Qt test suite до исправления.
- Регрессионный тест: `tests/test_ui_integration.py`
- Проверки исправления: 13 тестов и реальный macOS Cocoa-сценарий пройдены.
